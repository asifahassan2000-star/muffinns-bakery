# Lamina Bakehouse — Home and Menu handoff

## Files
- bakery-home-and-menu.html.txt: standalone HTML with embedded CSS and JavaScript. Rename to bakery-home-and-menu.html and open in a browser. Home and Menu use hash navigation.
- bakery-styles.css.txt: separate CSS copy for editing.
- bakery-interactions.js.txt: separate JavaScript copy for editing.
- bakery-design-reference.json: detailed inspected Framer reference, including responsive layouts, copy, styles, component definitions, interactions, and CMS content.

## Accuracy and limitations
This is a manually reconstructed standalone website, NOT Framer’s original generated HTML/CSS or a guaranteed pixel-identical export.
The original reference JSON preserves the inspected source settings for another AI to refine fidelity.
Images use original Unsplash photo identifiers recovered from project image metadata; project crop, processing, and exact appearance may differ. Embedded project asset references in the JSON require access to the original Framer project.
The original uses Framer spring animations, page wipe transitions, smooth scrolling and interactive variants. Standalone effects approximate these with CSS/JavaScript. Some decorative strokes, illustrations, and motion details are not replicated.
Only Home and Menu are recreated. About, Journal and Contact navigation leads to related homepage sections. Product detail pages, full journal pages, ordering, and newsletter backends are not included. Pre-order links open email; subscription form explicitly states demo status.
No project content was modified.

## For your AI
Use the standalone code as a starting implementation and the reference JSON as the authority for typography, exact copy, spacing, breakpoints, image placement, colors, component variants, and animation settings. Do not redesign. Preserve cream/mustard/crust palette, League Gothic headlines, Instrument Serif body, Oswald labels, Caveat annotations, outlined pills, generous spacing, and original section order. Reconnect the original project image assets and external services before production use.
